# empreendajacomsophi

Quero que você crie uma página de vendas ultra profissional, moderna, visualmente impactante e com alta conversão para o produto digital **Ecossistema EmpreendaJá com Soph**.

IMPORTANTE:

- esta página precisa parecer um produto digital premium e de alto valor

- não quero uma landing page comum

- não quero design genérico

- não quero simplificação visual

- quero uma página forte, elegante, futurista, corporativa, premium e memorável

- a página precisa vender de verdade

==================================================

1. DIREÇÃO VISUAL OBRIGATÓRIA

==================================================

A estética da página deve ser:

- Futurista + corporativa

- Tech + AI + Premium

- moderna

- forte

- chamativa

- com muito valor percebido

- bem estruturada

- com efeitos elegantes

Padrão visual obrigatório:

- dark mode sólido com camadas

- sem aparência lavada

- sem visual simples

- alto contraste

- branco puro nos textos importantes

- tipografia premium

- seções com boa profundidade visual

- layout extremamente bem distribuído

- cards sólidos com refinamento SaaS premium

==================================================

2. DESIGN SYSTEM OFICIAL

==================================================

Tipografia oficial:

- Fonte principal: **Manrope**

- Títulos principais: peso **800 ou 700**

- Títulos principais com **tracking-tight**

- Subtítulos e títulos secundários: **600**

- Textos corridos: **400**

- Labels, badges, mini destaques: **500 ou 600**

Cores oficiais:

- Fundo principal: **#0A192F**

- Superfícies profundas / áreas de contraste: **#041329**

- Cards / bases / áreas secundárias: **#102A43**

- Branco puro: **#FFFFFF**

- Ciano oficial: **#00EFFF**

Gradiente oficial:

- **#FFFFFF**

- **#F2FBFF**

- **#00FFFF**

Aplicação obrigatória do gradiente:

- usar o gradiente oficial nos **títulos principais**

- aplicar de forma correta, visível e premium

- o gradiente não pode ficar apagado ou mal distribuído

- usar visualmente no estilo:

  `background: linear-gradient(90deg, #FFFFFF 0%, #F2FBFF 45%, #00FFFF 100%)`

  com `background-clip: text` e texto transparente

- o gradiente deve aparecer principalmente em:

  - headline da hero

  - títulos principais de seções estratégicas

  - títulos de fechamento

  - alguns destaques premium

Não usar:

- verde como cor principal da página

- laranja como cor principal

- cinza apagado em textos relevantes

- tipografia sem peso

- títulos sem presença
